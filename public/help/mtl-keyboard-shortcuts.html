Keyboard Shortcuts

Jump around MountainTop Ledger without reaching for the mouse — quick, easy-to-learn key combinations that keep everyday bookkeeping moving.

A guide for business owners & bookkeepers
How they work

Hold two keys, then tap one

Press and hold Ctrl and Alt together, then tap a letter. On a Mac, that's Control and Option.

Because every shortcut needs both Ctrl and Alt held down, they never get in the way while you're typing in a field.

Tip: From anywhere in MTL, press Ctrl+Alt+/ to pop up this list on screen — no need to remember them all.

Easy to learn

Familiar keys, quick muscle memory

These use straightforward Ctrl+Alt letter combinations, matched to each feature so they're easy to remember — the letter usually echoes the action (I for invoice, B for banking, and so on). If you've used keyboard shortcuts in other accounting software, most of these will feel familiar right away.

More on the way: we can add shortcuts for actions inside a transaction too — like Save & new, Save & close, and Print. Let us know which ones you'd use most.
